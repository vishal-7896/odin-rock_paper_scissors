# Rock Paper Scissors Game 

A browser-based implementation of the rock paper scissors game built with javascript and HTML as part of **The Odin Project** foundations Curriculum.

##About the Project
This is the rock paper scissors game . The game runs for 5 rounds, tracks the scores for both the user and the computer and declares the winner at the end in the browser console.

#How to Play
1.Clone or download this repository to your machine.
2.Open the `index.html` file in a web browser.
3.Open the browser's **Developer Console** to view the game prompts, round results and final Scores.
4.Enter your choice (`rock`,`paper`,`scissors`) when prompted.
